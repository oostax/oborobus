## Tools

- `data_list`: List files under a local data directory.
- `data_read`: Read a UTF-8 text file from the local data directory.
- `data_write`: Write a UTF-8 text file to the local data directory.
- `git_branch_history`: View git branch history.
- `git_diff`: See changed files.
- `git_persistent_file_list`: List files in a git repo branch (.git files only).
- `git_status`: Check git repository status.
- `send_photo`: Send image to the owner's chat.
- `send_user_message`: Send a proactive message to the user.
- `update_scratchpad`: Append to persistent storage (scratchpad).
